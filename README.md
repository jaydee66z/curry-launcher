# Curry Launcher

Launcher personalizado para Roblox, escrito en Java.

## Estado
🚧 En desarrollo — estructura base recién creada.

## Cómo colaborar
1. Clona el repo: `git clone <url-del-repo>`
2. Lee `CLAUDE.md` — tiene las convenciones del proyecto y cómo está organizado.
3. Crea tu rama desde `dev`: `git checkout -b feature/tu-nombre dev`
4. Haz tus cambios, commit, push, y abre un Pull Request hacia `dev`.

## Requisitos
- Java 17+
- Maven

## Build
```bash
mvn clean package
```
